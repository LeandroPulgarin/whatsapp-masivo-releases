# WhatsApp Masivo — descargas

Instaladores de WhatsApp Masivo para Windows.

Descarga el archivo `WhatsApp Masivo Setup <versión>.exe` de la [última versión](https://github.com/LeandroPulgarin/whatsapp-masivo-releases/releases/latest).

La aplicación instalada busca versiones nuevas sola cada vez que se abre.
